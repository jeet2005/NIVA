# NIVA Product Vision

NIVA is a local-first Android personal assistant that understands relationships among a user's plans, tasks, deadlines, preferences, and relevant external context. Its long-term loop is to observe, normalize, understand, remember, predict, plan, explain, request authorization, act, verify, learn, and replan.

The product should distinguish confirmed facts from assumptions, stale information, estimates, and unknowns. Scheduling and permissions remain deterministic application responsibilities. AI assists with language understanding, structured intent, typed-tool selection, and concise evidence-backed explanations. Consequential actions require appropriate user authorization, and action outcomes must be verified before being described as complete.

NIVA should remain useful offline for supported local planning. External integrations should be optional, privacy-conscious, and cost-aware. No interface, mock, or persisted schedule alone establishes an external or device behavior as working.

The stated 1–2% complete-product figure is an initial strategic estimate only. It is not measured code coverage or a feature-completion score. See [feature-matrix.md](feature-matrix.md) for current evidence-based classifications.
